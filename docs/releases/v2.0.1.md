# agent-stack-go 2.0.1

The `agent-conform` image, `ghcr.io/taipanbox/agent-conform`, is signed in the legacy `.sig` format that the cluster admission controller (policy-controller v0.15.1) reads. Its reader takes only that tag, so the image signature was not verifiable there before this release. cosign stays at v3.1.3, and the release workflow's `sign-blob` steps are unchanged. Nothing else changed: the module, the exported API and the wire formats are the same as 2.0.0.

Commits since 2.0.0: one, #87 (`ci(release): sign the agent-conform image in the legacy format policy-controller reads`). It holds the signing change and also moves the README status badge and install lines to this version.

## Upgrade

Nothing to change in a consumer. The module path stays `github.com/TAIPANBOX/agent-stack-go/v2`, and `go get github.com/TAIPANBOX/agent-stack-go/v2@v2.0.1` picks up the same code as 2.0.0.

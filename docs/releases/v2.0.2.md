# agent-stack-go 2.0.2

The module and the `agent-conform` image are built with Go 1.27.3, which fixes GO-2026-6809 in `crypto/x509`. The 2.0.1 image was built with Go 1.27.2. Nothing else changed: the module path, the exported API and the wire formats are the same as 2.0.1.

Commits since 2.0.1: #89 (`build: Go 1.27.3 for GO-2026-6809 in crypto/x509`) and #90 (actions pinned to newer commits).

## Upgrade

Nothing to change in a consumer. `go get github.com/TAIPANBOX/agent-stack-go/v2@v2.0.2` picks up the same code as 2.0.1. A launcher that pins `ghcr.io/taipanbox/agent-conform` moves its pin to `v2.0.2` and the digest this tag's release workflow publishes.

## Not measured

- The release workflow has not yet run with the newer action pins from #90; this tag is its first run.
- The image built by this tag has not been run on a live box.

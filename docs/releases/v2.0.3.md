# agent-stack-go 2.0.3

The module and the `agent-conform` image are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The 2.0.2 image and binaries were built with Go 1.27.3. The module path, the exported API and the wire formats are the same as in 2.0.2.

Commits since 2.0.2: #96 (`build: Go 1.27.4 for GO-2026-6859`: the `toolchain` line in `go.mod`, the Go version of CI and of the release workflow, and the build image in the `Dockerfile`, pinned by digest), #95 (actions pinned to newer commits) and four README commits (#92 to #94): the version the README names, the eleven importers, and the stack diagram.

## Upgrade

Nothing to change in a consumer. `go get github.com/TAIPANBOX/agent-stack-go/v2@v2.0.3` picks up the same code as 2.0.2. A launcher that pins `ghcr.io/taipanbox/agent-conform` moves its pin to `v2.0.3` and the digest this tag's release workflow publishes. To roll back, pin 2.0.2 again.
